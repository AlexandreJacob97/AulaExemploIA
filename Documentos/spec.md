Papel: Atue como analista de requisitos senior.


Contexto: Uma pessoa organiza estudos de atividades que precisa manter as lista desse funcionando e salva, mesmo fechando o site.


Objetivo: Especificar um MVP de tarefas, dar cheque se completado e adicionar um botão de remover a tarefa da lista. Possuir uma nominação na tarefa de Pendente e concluída.


Escopo: CRUD, status e filtros simples sem uma necessidade de elaborar um frontend complexo.


Restrições: Sem login nem funções extras, um sistema básico para o usuário.


Saída: Lista de requisitos + testes, preenchendo os requerimentos de acima.

Usuário: Estudante organizadno a semana.

Objetivo: Visualizar a gerencia de tarefas.

Funcionalidades: Criar, editar, concluir, excluir, filtrar

Estados: Vázio, carregando, erro sucesso.

Design: Simples, responsivo, acessível.

Limites: Sem login e sem serviço de dados novo.
